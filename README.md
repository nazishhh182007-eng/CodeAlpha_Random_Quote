# CodeAlpha Random Quote Generator

A simple and interactive Random Quote Generator developed as part of my CodeAlpha Internship.

## Features

- Displays a random quote when the app opens
- Generates a new quote when the button is clicked
- Shows quote text and author name
- Clean and minimal user interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Internship

Developed for the CodeAlpha Internship Program.
